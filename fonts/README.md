# Fonty

Fonty webu jsou uložené přímo tady, ne načítané z Google Fonts. Prohlížeč
návštěvníka tak kvůli písmu nekomunikuje se servery Googlu (GDPR) a stránka
nemusí navazovat spojení s další doménou.

Soubory jsou beze změny převzaté z balíčků Fontsource (verze 5.3.0), které
obsahují stejná písma jako Google Fonts. Deklarace `@font-face` jsou na začátku
`style.css`.

| Písmo | Balíček | Řezy | Licence |
| --- | --- | --- | --- |
| Cormorant Garamond | `@fontsource-variable/cormorant-garamond` | 300–700 (variabilní) | `OFL-cormorant-garamond.txt` |
| Raleway | `@fontsource-variable/raleway` | 100–900 (variabilní) | `OFL-raleway.txt` |
| Tenor Sans | `@fontsource/tenor-sans` | 400 | `OFL-tenor-sans.txt` |
| Lavishly Yours | `@fontsource/lavishly-yours` | 400 | `OFL-lavishly-yours.txt` |

Každé písmo má soubor `-latin` (základní latinka) a `-latin-ext` (mimo jiné
česká diakritika). Všechna písma jsou pod licencí SIL Open Font License 1.1.
